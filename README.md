# Apps de Engenharia

Coleção de aplicativos de engenharia em HTML autocontido (sem instalação, rodam no navegador).

| App | Descrição | Pasta |
|-----|-----------|-------|
| Decanta | Avaliação de decantadores líquido-líquido (DEP) e captura em internos (ACS) | [`decanta/`](decanta/) |

## Uso

Publicado via GitHub Pages: abra a URL do site e escolha o app.
Offline: baixe o `index.html` da pasta do app e abra no navegador.

## Adicionar um app

1. Crie uma pasta `nome-do-app/` com um `index.html`.
2. Adicione um cartão em `index.html` (raiz) e uma linha na tabela acima.
3. Commit + push — o Pages atualiza em ~1 minuto.

> Não versionar dados de clientes (casos `.json`, planilhas). Os apps salvam/carregam casos localmente.
